## The entry

> A zipper is a tiny bridge-builder: a slider walks along two banks of metal teeth and locks their hands together, one pair at a time, until the gap is gone.
>
> It works because the teeth really do lock together, pair by pair, but it leaves out that a real bridge stays standing — a zipper can spring open the moment one tooth lets go.

## Description

A two-line explanation of an everyday thing for a 10-year-old, written for the
make.fun competition "Everyday Things, Two Lines, Longer Run". Line 1 explains
a zipper through a single concrete analogy — a tiny bridge-builder locking
hands across a gap — and line 2 says honestly what that analogy maps and what
it leaves out.

`main.ts` (Node 22, standard library only, deterministic, no network) writes
exactly those two lines to `entry.txt` in the output directory, enforcing the
two-line and 1–400 character limits before writing.

## Run

```sh
node main.ts
```

This writes `/output/entry.txt`. To write elsewhere:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
